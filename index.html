Cómo se toca

  • 🤏🤏Pinza con las dos manos (pulgar + índice): aparece una cuerda entre ellas. Soltá y queda fija.
  • 🤏Pinza y arrastrá con una mano (o pinza con las dos): aparece una cuerda. Soltá y queda fija.
  • ☝️Pasá el índice a través de una cuerda para tocarla. Larga = grave, corta = aguda.
  • 🖱️Con el mouse: arrastrá para crear, pasá por encima para tocar.
  • 👆Con el dedo en la pantalla: arrastrá para crear, deslizá a través de una cuerda para tocarla.
